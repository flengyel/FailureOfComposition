# Cumulative Eight checkpoint

This audit directory contains the exact interface checker, per-root dependency
and route audit, negative regressions, source-policy adapter, stable-export
commands, protected-configuration preparation, and bounded Comparator launcher
for `range_counterexample_productive` and the cumulative eight-result pair.

The eighth selected declaration has the same public Proposition 6 statement as
the seventh declaration.  Its proof closure is required to reach the maintained
productive/history route and to exclude the Gödel-II/Craig range route.  The
negative route fixture has the exact theorem type but deliberately calls the
seventh theorem; its missing productive root is rejected by the route audit.

The portable configuration under `Lean/` contains no machine-local kernel
commands. `prepare_comparator.py` creates a protected local copy by adding only
the authenticated con-ron and NanoDa commands. Full exports remain in the
retained `.codex-work` run tree and are identified by hashes in the final result.
